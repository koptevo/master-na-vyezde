# Лендинг без бэкенда

## Правило
Одна страница = один файл HTML, один CSS, один JS. Любая заявка уходит в WhatsApp клиента, а не «в никуда».

## Как
```js
const url = `https://wa.me/79997564111?text=${encodeURIComponent(text)}`;
window.open(url, '_blank', 'noopener');
```

## Почему
Клиент уже ведёт заказы в WhatsApp — не надо переучиваться и платить за CRM.

## Исключения
Если появится бэкенд — заменить только обработчик `submit` в `script.js`.

## Дополнительно
- Никаких unverified-обещаний: гарантия, цены, отзывы и фото добавляются только после подтверждения.
- Все иконки — SVG, не эмодзи. Минимальная цель нажатия 44×44 px.
- Форма: `<label for>`, `inputmode`, ошибка рядом с полем, состояние «отправляем → готово».

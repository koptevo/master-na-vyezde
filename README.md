# Мастер на выезде — демо-лендинг

Одностраничный сайт для мастера, который чинит стиральные машины **на дому**: без офиса и физического сервиса.

Открыть: двойной клик по `index.html`. Сборка и зависимости не нужны — весь CSS внутри страницы, шрифт системный.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка, тексты, стили, SVG-иллюстрация, иконки |
| `script.js` | Тема, появление блоков, маска телефона, заявка в WhatsApp |
| `_old/` | Прежняя версия (синяя, с отдельным `styles.css`) — на всякий случай |
| `design-system/` | Дизайн-система первой версии |
| `agent-os/` | Спека, задачи и стандарт проекта |

## Стиль

Редакционный светлый: бумага `#f7f5f1`, карточки `#fffdfa`, чернила `#1c2326`, один акцент — приглушённый бирюзово-синий `#2f6b86`. Тонкие линии, номера секций `01…07`, скругления 3 px, никаких градиентов и теней. Шрифт — системный Helvetica/Arial, чтобы страница не зависела от Google Fonts.

## Тёмная тема

Кнопка с солнцем/луной в шапке. Выбор сохраняется в `localStorage`, при первом открытии берётся системная настройка `prefers-color-scheme`. Все цвета — на CSS-переменных `:root` и `[data-theme="dark"]`.

## Что заменить перед публикацией

1. **Телефон** — `79997564111` и `+7 999 756-41-11`. Сейчас это номер из переписки, а не подтверждённый рабочий. Встречается в шапке, герое, форме, мобильной кнопке и подвале.
2. **Название** — «Мастер на выезде». Рабочее: клиент сказал, что названия нет.
3. **Цены** — таблица «Сколько стоит» собрана по средним значениям, клиент их не подтверждал.
4. **Гарантия 12 месяцев** — не подтверждена. Если мастер даёт другой срок, поправить в пяти местах.
5. **Марки** — «Bosch, LG, Samsung, Indesit, Candy, Electrolux». Список не подтверждён, лучше уточнить.
6. **Демо-пометка** — плашка сверху ведёт на портфолио. Удалить `<a class="demo-flag">` перед публикацией.
7. **Фото** — вместо фотографий SVG-иллюстрация с подписью «заменим на ваши фото».

## Чего на странице нет (намеренно)

- Часов работы, адреса и карты — физического сервиса нет.
- Отзывов и фото клиента — не присылал.
- Онлайн-оплаты и бэкенда — заявка уходит в WhatsApp.

## Как работает форма

Поля: имя, телефон, марка (необязательно), поломка. При отправке:

1. Имя и телефон проверяются, ошибка выводится строкой над кнопкой (`#leadErr`).
2. Из данных собирается текст заявки.
3. Открывается `https://wa.me/79997564111?text=…` с готовым сообщением.
4. Данные никуда не отправляются, кроме WhatsApp.

- 390, 820 и 1440 px — горизонтальной прокрутки нет, мобильная панель кнопок не перекрывает подвал.
- Тема переключается и запоминается, мета `theme-color` меняется.

- FAQ раскрывается, `prefers-reduced-motion` уважается.
- Ошибок в консоли нет.

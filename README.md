# Мастер на выезде — демо-лендинг

Одностраничный сайт для клиента, который чинит стиральные машины **только на выезде**: без офиса, названия и фиксированных часов.

Открыть: двойной клик по `index.html`. Сборка, зависимости и интернет не нужны (шрифты подгрузятся, если есть сеть; без сети сработает системный шрифт).

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка, тексты, SVG-иллюстрация и иконки |
| `styles.css` | Цвета, сетки, адаптив, состояния форм |
| `script.js` | Маска телефона, валидация, переход в WhatsApp |
| `design-system/` | Дизайн-система (палитра: синий, белый, чёрный) |
| `agent-os/` | Спека, задачи и стандарт проекта |

## Что заменить перед публикацией

Поиском по файлам:

1. **Телефон** — `79997564111` и `+7 999 756-41-11`. Сейчас это номер клиента из переписки. Встречается в шапке ссылок, форме, кнопках и подвале.
2. **Название** — «Мастер на выезде» / «Мастер по ремонту стиральных машин на дому». Рабочее, клиент сказал, что названия нет.
3. **Демо-пометки** — поиск по `demo-note`: плашка сверху и строка в подвале. Удалить перед публикацией.
4. **Марки** — строка «Например: Bosch, LG, Samsung, Indesit». Клиент не подтверждал список, лучше уточнить.
5. **Формулировки** — «Цену скажем после осмотра», «Время приезда согласуем». Это безопасно, но если клиент приезжает в день обращения — замените на конкретику.

## Палитра

Только три цвета: **синий** `#1D4ED8` (акцент, кнопки, ссылки), **белый** и **чёрный** (фон, текст, границы). Оранжевого нет — все акценты переведены на синий, включая иконки и иллюстрацию.

## Тёмная тема

Кнопка «Тёмная / Светлая» с луной и солнцем в шапке переключает тему. Выбор сохраняется в `localStorage`, при первом открытии тема берётся из системной настройки `prefers-color-scheme`. Вместе с фоном меняются карточки, текст, иконки и иллюстрация стиралки — все цвета завязаны на CSS-переменные в `styles.css`.

## Чего на странице НЕТ (намеренно)

- Часов работы, адреса, карты проезда — клиент сказал, что физического сервиса нет.
- Гарантии «12 месяцев» — не подтверждено.
- Отзывов и фотографий — клиент не прислал. Вместо фото векторная иллюстрация, не чужой шаблон.
- Онлайн-оплаты и бэкенда — заявка уходит туда, где клиент уже принимает заказы.

## Как работает форма

Поля: имя, телефон, марка (необязательно), поломка. При отправке:

1. Поля проверяются, ошибка показывается прямо под полем.
2. Из данных собирается текст заявки.
3. Открывается `https://wa.me/79997564111?text=…` с готовым сообщением — клиенту не надо ничего переписывать.
4. Ниже есть запасная ссылка «Написать напрямую», если браузер заблокировал открытие чата.

Данные никуда не отправляются, кроме WhatsApp. Чтобы подключить CRM или бот — замените обработчик `submit` в `script.js`.

## Публикация

- **Netlify Drop** — перетащить папку `stiralny-master` на netlify.com/drop, ссылка готова за минуту.
- **GitHub Pages / любой статический хостинг** — загрузить `index.html`, `styles.css`, `script.js`.

## Проверено

- Ширины 375, 768, 1024, 1440 px — горизонтальной прокрутки нет.
- Клавиатура, видимый фокус, подписи к полям, `role="alert"` и `role="status"`.
- `prefers-reduced-motion` уважается.
- Иконки — SVG, без эмодзи; размеры целей нажатия от 44 px.
